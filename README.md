# 📊 Sales & Operations Performance Dashboard (Power BI)

## 🚀 Overview

This project analyzes sales performance, profitability, and operational efficiency across Indian cities using Power BI.

---

## 📈 Key Insights

* Metro cities generate highest revenue
* UPI & Credit Card dominate payments
* Delivered orders have higher ratings
* Profit varies significantly by city
